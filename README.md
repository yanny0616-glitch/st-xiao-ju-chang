# 小剧场 · SillyTavern 扩展

给当前聊天的角色点一下，出一篇小剧场：可能是一段小说体，也可能是 AI 当场写的一整页 HTML（弹幕、聊天截图、论坛帖、可以翻的塔罗牌）。HTML/JS 放在沙盒 iframe 里直接渲染，不需要写正则。

适配原版 SillyTavern 和 [TauriTavern](https://github.com/Darkatse/TauriTavern)，电脑和手机（含 iPhone 16 Pro 的刘海和底部横条安全区）都能用。

## 安装

酒馆 → 扩展 → 安装扩展，填仓库地址：

```
https://github.com/yanny0616-glitch/st-xiao-ju-chang
```

装好后从输入框左边的魔杖菜单打开「小剧场」，或者在扩展设置里找到「小剧场」点「打开小剧场」。

## 用法

- **舞台**：直接用当前聊天的角色，提示词里写 `{{char}}`、`{{user}}` 就行（不支持群聊）。选一个小剧场，点「生成一篇」；「随机」按权重抽，「AI 自选」把形式库给模型自己挑。结果可以再来一条、收藏、全屏、复制、挂到聊天。AI 写的按钮带 `data-action` 时，点了会带着这个选择接着写一篇。
- **库**：小剧场 = 前置要求 + 几条提示词 + 随机规则 + 输出方式 + 上下文。四类部件各自成库，随便组合。支持批量导入「## 标题 #标签」文本、本扩展导出的包、Float 小剧场 APP 导出的包；酒馆预设、世界书、角色卡这类 JSON 会列出里面像提示词的段落让你挑。
- **收藏**：收藏会存下当时用的配置，可以「按这套再来」。「本聊天」列出挂在这个聊天消息下面的所有小剧场。
- **聊天内**：消息的「…」菜单里有面具按钮，点了为这条消息出一篇，挂在消息下面。也可以开「AI 回复后自动出」并设概率。这些小剧场存在消息的 extra 里，跟着 swipe 走，**不会发给模型**。
- **设置 → API**：可以在扩展里直接配 API（OpenAI 兼容 / Claude / Gemini），能拉模型列表、测试连接，每个小剧场可以单独选出口。请求经酒馆后端转发，没有跨域问题。也可以用「跟随酒馆当前 API」或酒馆的连接配置。

## 发给模型的是什么

1. 材料（system）：角色卡（描述、性格、场景），用户人设，世界书（按聊天内容激活，和酒馆一样），「总结」扩展的剧情总结，最近 N 轮聊天。每样都可以在小剧场里关掉。
2. 前置要求（system）。
3. `<Brief>`（user）：身份、提示词、抽中的随机条目、输出要求。

酒馆预设里的破限、文风、正文格式条目都不会带进来，需要的话写进前置要求。宏先在扩展里展开（`{{随机词:世界}}` `{{随机数:好感}}` `{{roll:1d6}}` `{{篇幅}}` 等），剩下的交给酒馆，所以 `{{getvar::}}` 这类酒馆宏也能用。

## 数据存在哪

- TauriTavern：宿主的扩展存储（`data/_tauritavern/extension-store/xiao-ju-chang/`），随数据目录一起备份和同步。
- 原版酒馆：库、设置和 API 配置存在 `extension_settings`（服务器 `settings.json`）；收藏和最近存在浏览器 IndexedDB（换浏览器不跟着走，用「设置 → 数据」导出导入）。

自配 API 的密钥明文保存在上述位置，导出时默认不带。

## 和 Float 小剧场 APP 的差别

去掉了：宿主记忆三选一（改成聊天上下文 + 世界书 + 总结）、写回记忆、纯裸通道（扩展本来就自己拼上下文）、四套整体主题（改成跟随酒馆 UI 主题，小剧场画布可选跟随主题 / 纸张 / 夜色）。

加上了：聊天消息下挂小剧场（手动 / 自动）、扩展内配 API、酒馆连接配置、世界书按聊天激活、剧情总结、酒馆宏。

## 开发

纯前端 ES 模块，没有构建步骤。端到端测试需要一个本地酒馆、Chromium 和 playwright：

```bash
node tests/mock-ai.mjs &                      # 模拟 OpenAI 兼容接口，端口 5297
# 酒馆的聊天 API 指向 http://127.0.0.1:5297/v1，把本仓库放进 data/default-user/extensions/st-xiao-ju-chang
ST_URL=http://127.0.0.1:8000 MOCK_LOG=/tmp/mock.log node tests/e2e.cjs
```

测试用的角色和世界书都是虚构的，每次运行前会清掉上次的测试数据。
