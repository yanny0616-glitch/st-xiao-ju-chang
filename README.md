# 小剧场 · SillyTavern 扩展

给当前聊天的角色点一下，出一篇小剧场：可能是一段小说体，也可能是 AI 当场写的一整页 HTML（弹幕、聊天截图、论坛帖、可以翻的塔罗牌）。HTML/JS 放在沙盒 iframe 里直接渲染，不需要写正则。

适配原版 SillyTavern 和 [TauriTavern](https://github.com/Darkatse/TauriTavern)，电脑和手机（含 iPhone 16 Pro 的刘海和底部横条安全区）都能用。

## 安装

酒馆 → 扩展 → 安装扩展，填仓库地址：

```
https://github.com/yanny0616-glitch/st-xiao-ju-chang
```

装好后从输入框左边的魔杖菜单打开「小剧场」，或者在扩展设置里找到「小剧场」点「打开小剧场」。

## 用法

- **舞台**：直接用当前聊天的角色，提示词里写 `{{char}}`、`{{user}}` 就行（不支持群聊）。舞台上是当前要演的小剧场，点卡片或「换一个」弹出列表换（可搜索、按标签筛；每行的 ☆ 标成爱用，爱用的排在最前，筛选里点「★ 爱用」只看爱用的；👁 打开详情，能看前置、每段提示词全文和 HTML 规范，底下有爱用 / 编辑 / 用这个）；「直接用提示词」里每条也能 👁 看全文，详情里可以编辑或选上；不想先建小剧场的话，列表里切到「直接用提示词」，点选一条或几条，再选前置要求和形式（纯文字 / HTML / 混排）就能直接生成（其他跟随全局），舞台上标「临时」，好用再「存成小剧场」。新建提示词时也可以勾「同时建成一个小剧场」。带随机抽取的小剧场，卡片上有「这次抽」：点「指定」按段列出可能抽到的条目，挑一条或几条，接下来就用它们（不改小剧场本身，「改回随机」或换小剧场就恢复；「按这套再来」照常随机）。选好后点「生成一篇」（想给这一次额外交代几句，点开「＋ 这次附加要求」填，平时折叠着；楼层的面具按钮也可以在「设置 → 聊天内」设成先问一句）；「随机」按权重抽，「AI 自选」把形式库（带「形式」标签的提示词，一条都没有就用全部提示词）给模型自己挑。结果卡右上角是全屏（点标题也行；电脑上和面板一样大、居中，点外面暗处就关）；还可以再来一条、收藏、复制、挂到聊天，或者「接着写 / 追问」：带上这一篇的正文（接着写过几次的再往前带两篇），用同一套前置和提示词、沿用这一篇随机抽到的，接着往下写一篇，或者就这一篇提问（比如塔罗读完再问「那逆位呢」），可以选和原来一样的形式或纯文字；接出来的那篇也能再接，「再来一条」会接着同一篇重写。楼层里的小剧场标题栏也有回复图标，点开小输入框就能接着写或追问，新的一篇挂在同一楼。编辑、删除、改名、复制这类按钮是图标，悬停能看到说明。「ⓘ」里能看到这篇用了哪些部件、每一步实际发给模型的内容（可复制）和模型原文；「走酒馆预设」的小剧场记下的是酒馆按预设拼好、真正发出去的那份。AI 写的按钮带 `data-action` 时，点了会带着这个选择接着写一篇。 舞台下面的「最近」默认折叠，点标题展开，展开或折叠会记住。
- **长图 / 导出**：结果卡片和全屏页上有两个图标：🖼 保存长图（整篇画成一张 PNG，HTML 小剧场按当前点开的状态截，很长的会自动降一点清晰度）；📄 导出小剧场（存成一个单独的 .html，打开就能看、能点）。TauriTavern 里走它的保存面板，浏览器里直接下载。聊天楼层里的小剧场点「全屏」后也能用。截图用的是 [modern-screenshot](https://github.com/qq15725/modern-screenshot)（MIT，放在 `vendor/`）。
- **流式和提醒**：所有出口都发流式请求，「跟随酒馆当前 API」和「走酒馆预设」也是（酒馆里流式关着也一样；参数还是按酒馆当前连接拼）。一直有数据在走，写两三百秒的长篇也不会被中转站或反代超时掐断（504）；边写边显示可以在设置里关。酒馆用的是文本补全时还是一次性返回。写好了的时候，如果你不在小剧场面板上（面板关着、不在舞台），酒馆顶上弹一条「小剧场写好了」（就是酒馆自己的提示，位置和酒馆其他提示一样），点了回到那篇；楼层里出的那篇不在屏幕上时也会弹，点了滚到那一楼。切到别的 App 或标签页时，等你回来再弹。在「设置 → 生成」里可以关。
- **库**：小剧场 = 前置要求 + 按段排的提示词 + 随机附加 + 输出方式 + 上下文。提示词按「段」排，各段按顺序合成同一篇的要求（不会拆成几篇）：每段放几条提示词或整个分组（以后加进组的也算），可以全部用，也可以从里面随机抽几条。比如「主题」段放塔罗的 HTML（全部用），「牌阵」段放几种牌阵（随机抽 1 条）。五类部件（小剧场、提示词、随机池、前置、HTML 规范）各自成库，随便组合。提示词和随机条目可以放进分组（像文件夹，可放可不放）：库里按组显示、可折叠，组能改名、解散（条目回到「未分组」），还能「按第一个标签分组」一键整理；标签照旧用来筛选。库里能搜标题、内容、分组、标签。编辑小剧场时可以「保存并试生成」；「选提示词」按组列出，可以整组加入；随机附加（随机池里的小料，默认不抽，想要就在编辑里改成抽几条）可以选「从分组抽」，「只抽 / 排除」直接点标签。旧版里选在随机里的提示词分组，更新后会自动换成一段随机。导入时可以指定放进哪个分组。删提示词会从用到它的小剧场里摘掉；删前置要求时，用它的小剧场改用第一条。 分组用下拉选（未分组 / 已有分组 / ＋ 新建分组），提示词、随机池列表上可以直接「＋ 新建分组」并勾选要放进去的条目，分组标题上的「＋」继续往里放；标签点已有的就能选上或取消，也可以打新的回车加上。
- **导入**：批量导入「## 标题 #标签」文本，可选「每条同时建成一个小剧场」；本扩展导出的包、Float 小剧场 APP 导出的包、暗柜档案（aiInstruction / templateSnapshot）都能直接认；酒馆导出的世界书会列出条目（名字用条目标题，按酒馆里的顺序，蓝灯 / 绿灯标出来，酒馆里禁用的灰掉），勾选要的导入；也可以点「从酒馆世界书选」直接挑酒馆里已有的世界书，不用先导出。酒馆预设、角色卡这类 JSON 会列出里面像提示词的段落（带路径、可搜索、可展开全文）。勾选时可以选导成提示词 / 前置要求 / HTML 规范 / 随机条目，提示词和随机条目可以统一加标签、放进分组。
- **收藏 / 最近**：默认只看当前角色的，可以切到全部角色；收藏多了可以搜标题、小剧场、角色、提示词。收藏会存下当时用的配置，可以「按这套再来」「放到舞台」，可以按文字型 / 前端型筛选。「本聊天」列出挂在这个聊天消息下面的所有小剧场。
- **聊天内（可选，默认关）**：在「设置 → 聊天内」或扩展设置里打开「在楼层里显示小剧场」后，消息的「…」菜单里有面具按钮，点了为这条消息出一篇，挂在消息下面。也可以开「AI 回复后自动出」并设概率（换一个回复、重新生成时默认不自动出，可以打开）。收起时的样子在「设置 → 外观 → 楼层里的折叠样式」里选：胶囊（默认，只包住标题、几篇排一行）、细条、一行小字、标题栏，或者「自定」自己写 CSS（可以从任一内置样式开始改，边改边预览）；新挂上的默认收起。这些小剧场存在消息的 extra 里，挂在哪个回复（swipe）下就只在那个回复下显示，新生成的回复不会带上旧回复的，**不会发给模型**。
- **纯文字排版**：纯文字小剧场支持 Markdown：`#` 标题、`>` 引用、列表、分隔线、粗体、斜体、删除线、行内代码，`||剧透||` 点一下才显示。模型写的 HTML 标签在纯文字里照原样显示，不会执行。
- **设置 → 外观**：八套主题——杂志（米白纸面、宋体报头、首字下沉）、便签墙（彩色便签和胶带）、终端（黑底绿字、等宽、扫描线）、剧本（打字机字体、装订孔）四套照搬 Float 小剧场，另有夜读（深蓝夜色、琥珀灯）、信笺（粉笺楷体、邮戳）、糖果（马卡龙渐变、圆角）、宣纸（米黄宣纸、朱印、汉字序号）。面板、正文、全屏和聊天里挂的小剧场一起换，不跟酒馆主题走；想跟酒馆 UI 主题一致可以选「酒馆」。「界面字号」五档（特小～特大）整体缩放插件里所有文字，不跟酒馆的字号走；「正文字号」在此基础上单独调小剧场正文。输入框的字号跟着界面字号，颜色只用小剧场主题的，不吃酒馆主题的输入框样式。正文底色也能单独改成纸张或夜色，动效可以关。
- **自定义主题**：「新建自定义主题」基于任一内置主题，改 CSS 变量（`--xjc-ui-*` 管面板，`--xjc-canvas-*` 管正文）或写任意 CSS（选择器加 `[data-xjc-custom]`），另有一栏「正文 CSS」放进小剧场内容的 iframe 里。边改边预览，保存后和内置主题一起出现在列表里。可以「导入 CSS 文件」「导出 .css」，导出的文件带名字和基于哪套，再导入时原样还原。
- **跟随全局**：小剧场里的上下文材料、身份、通道、篇幅、出口、HTML 风格、分两步出、写回记忆，默认都「跟随全局」（全局值在「设置 → 生成 → 全局默认」）；想让某个小剧场不一样，在它的编辑页选「自定」或具体值。改了全局，所有跟随的小剧场一起变。用不到的选项会收起来（随机不抽时不显示只抽 / 排除，纯文字不显示 HTML 选项，不限篇幅时不显示篇幅，没开自动出时不显示概率）。
- **设置 → API**：可以在扩展里直接配 API（OpenAI 兼容 / Claude / Gemini），能拉模型列表、测试连接，每个小剧场可以单独选出口。请求经酒馆后端转发，没有跨域问题。也可以用「跟随酒馆当前 API」或酒馆的连接配置。

## 发给模型的是什么

默认（通道「插件自己拼」）：

1. 材料（system）：角色卡（描述、性格、场景），用户人设，世界书，「总结」扩展的剧情总结，最近 N 轮聊天。每样都可以在小剧场里关掉。
   聊天记录和酒馆发给模型的一样：隐藏的楼层不带，「修改提示词」类的正则照常生效（按深度）。在某一楼下出小剧场时，聊天截到那一楼，世界书也按截到那一楼、正则处理过的聊天来激活，扫描深度、绿灯关键词、蓝灯常驻都按酒馆的世界书设置——所以数据库插件写在用户消息里的召回编码，和在酒馆里正常发消息时一样点亮对应的绿灯条目。
   世界书来源在「设置 → 生成」里二选一：**同步酒馆**（默认，和酒馆聊天时用的一样：全局选的 + 角色卡、聊天、人设绑定的）；**自己选**（列出酒馆里所有世界书，默认勾上酒馆现在开着的和当前角色卡、聊天、人设绑定的，在这上面增减；每本书默认收起，点书名展开条目，每条直接显示酒馆里的状态：蓝灯 / 绿灯、插入位置、是否禁用，开了几条 / 共几条（只显示，要改去酒馆的世界书里改）；换了角色，新角色卡绑定的书也默认勾上；不改酒馆自己的世界书设置）。两种都照上面的规则激活。
   世界书不设预算：激活了就全带上，不管酒馆世界书设置里的百分比和预算上限。各个位置的条目都带：角色定义前后、作者注释前后、示例消息前后放进 `<WorldInfo>`；@深度的条目（数据库插件的记忆默认在 @深度 2）像酒馆一样按深度插进聊天记录。
2. 前置要求（system）。
3. `<Brief>`（user）：身份、提示词、抽中的随机条目、HTML 规范、输出要求。
   **HTML 规范**是库里的一类（「库 → HTML」）：HTML 怎么写的规定（布局、尺寸、字号、能不能引外部资源……），自带一条「手机通用」，可以加自己的，比如把一整套前端小剧场规则存成一条。小剧场输出是 HTML 或混排时（分两步的骨架也算）带上选中的那条；每个小剧场在「编辑 → 输出 → HTML 规范」选跟随全局 / 某一条 / 不带，全局默认在「设置 → 生成」里选。纯文字不带。0.5.1 以前改过的内置「HTML 规则」更新后自动变成库里一条并设为默认；以前靠「前端」标签不带规则的 HTML 小剧场自动改成「不带」。
   身份、输出要求（纯文字 / HTML / 混排、篇幅、标题、标签包裹、HTML 风格）、分两步出的两步、楼层下出、按钮接着写、AI 自选这些插件自己加的话，都能在「设置 → 生成 → 内置指令」里改，可以单条或全部恢复默认。全局身份选「自定身份」时，身份写在全局默认里。

酒馆预设里的破限、文风、正文格式条目都不会带进来，需要的话写进前置要求；或者把小剧场的通道改成「走酒馆预设」：用酒馆自己的完整生成流程（预设、角色卡、世界书、聊天记录都由酒馆拼），小剧场只补前置要求和 `<Brief>`。这个通道只对「跟随酒馆当前 API」有效（出口选了别的，编辑页里就不显示通道），不流式；在更早的楼层下出时酒馆没法截掉之后的聊天，会自动改用插件自己拼，「ⓘ」里注明。

**写回记忆**（可选功能，默认关；在「设置 → 生成 → 可选功能」打开后，每个小剧场里才有这个开关）：生成后把梗概（约 400 字）写成一条常驻世界书条目，放进这个聊天绑定的世界书；聊天还没绑世界书就新建一本「小剧场记忆 · 角色名 · …」并绑上。之后正常聊天时模型就记得这件事。宏先在扩展里展开（`{{随机词:世界}}` `{{随机数:好感}}` `{{roll:1d6}}` `{{篇幅}}` 等），剩下的交给酒馆，所以 `{{getvar::}}` 这类酒馆宏也能用。

## 数据存在哪

- TauriTavern：宿主的扩展存储（`data/_tauritavern/extension-store/xiao-ju-chang/`），随数据目录一起备份和同步。
- 原版酒馆：库和设置存在 `extension_settings`（服务器 `settings.json`）；收藏、最近和 API 配置（含密钥）存成服务器上的用户文件 `data/<用户>/user/files/xiao-ju-chang-*.json`，换设备、换浏览器都在，也不会随 `settings.json` 被分享出去。以前存在浏览器里的收藏、最近和 settings.json 里的 API 配置，更新后第一次打开时自动搬过去。

自配 API 的密钥明文保存在上述位置，导出时默认不带。

## 和 Float 小剧场 APP 的差别

改成酒馆的做法：宿主记忆三选一 → 聊天上下文 + 世界书 + 总结；写回记忆 → 写进聊天绑定的世界书；宿主预设 / 纯裸通道 → 「走酒馆预设」/「插件自己拼」。

没搬：主演选择和按角色分开（扩展跟着当前聊天的角色走）。

加上了：聊天消息下挂小剧场（手动 / 自动）、扩展内配 API、酒馆连接配置、世界书按聊天激活、剧情总结、酒馆宏。

## 开发

纯前端 ES 模块，没有构建步骤。端到端测试需要一个本地酒馆、Chromium 和 playwright：

```bash
node tests/mock-ai.mjs &                      # 模拟 OpenAI 兼容接口，端口 5297
# 酒馆的聊天 API 指向 http://127.0.0.1:5297/v1，把本仓库放进 data/default-user/extensions/st-xiao-ju-chang
ST_URL=http://127.0.0.1:8000 MOCK_LOG=/tmp/mock.log node tests/e2e.cjs
```

测试用的角色和世界书都是虚构的，每次运行前会清掉上次的测试数据。
